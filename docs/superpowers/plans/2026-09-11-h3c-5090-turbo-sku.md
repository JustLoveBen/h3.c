## 3. 重点方案：极速视角的短判

### 3.1 FastH3 4-step LoRA — 极速主候选 α

- **做什么：** DMD2 把 ~49 次 teacher forward 蒸成 4 次（sigma `1000,750,500,250→0`）。学生是 LoRA，不是 INT8 骨干。VSA 跟学生一起训（video-video ~10% tile；text/audio 永远 dense）。
- **对本仓：** 这是墙钟数量级的 **唯一合法主刀**（匹配学生，不是拧 `--steps`）。隔离跑 FastVideo/Triton 对照，再决定是否写 C 加载器。
- **5090：** 权硬件无关。快核 `sm100a` **不在 sm_120 资格集** → 5090 不要赌 CUDA VSA；dense 4-step 或 Triton VSA 才是可移植路径。32GB 上 BF16 768p 常驻失败；**480p 4-step BF16 是否常驻未测**。产品路径优先 **INT8 骨干 + 运行时 LoRA**（反量化 LoRA 层或 merge 后保持 INT8 学生——数值合同必须先写）。
- **质量：** Preview 明确非无损。极速底线「能看」与它的产品定位对齐。T2VA only。
- **不要：** merge 进金线 INT8；把 B200 47.2s/14.38× 写 5090。

### 3.2 RH / LightX2V / larryvrh turbo LoRA — 主候选 β（与 α 二选一）

- **larryvrh v4：** 公开 4-step；RH 复现用这条。作者：**4 是下限、6–8 更好**，大运动 smear。高动态 RH 自己回 8。
- **LightX2V T2VA：** 默认图常是 **8-step v1.0** → 对极速 **不是** 少步刀。另有 4-step / Turbo-SLA（FL2V、85% 稀疏 + Sage2），任务不是本仓 T2VA 金线。
- **RH 自训权未公开。** 12.2× 的 95.5% 来自 50→4，与多卡无关。Sage2+Cache+compile 只再 ×1.50。
- **对本仓：** 公开 4-step LoRA 与 FastH3 **只落地一条**（P3.2 原合同）。选谁看人眼 cafe：谁更不崩主体、谁更有声。不要并行两条加载器。
- **Cache-DiT 在已是 4-step 上跳步空间极窄**（`max_warmup_steps=4`）。极速档 **不要**再叠 Mag/Tea。

### 3.3 Sol 二采 — 拆成有/无 LTX

| 变体 | 判决 |
| --- | --- |
| H3 4-step 低分 + **LTX 3-step** + TAEHV（Super Accel） | **本仓不能跑。** 无 LTX / TAEHV / `cute_sm100`。6.85s **禁止**写 5090。 |
| H3→H3 480p 草稿 + 768p FL2VA | **8+8 更慢**（[two-stage-768p](./2026-09-11-h3c-two-stage-768p.md)）。不是 480p 极速的事。 |
| 低分 4-step + 高分 2–4 步匹配学生 | 768p 快档备选；仍难打穿 TE+VAE 地板。音频跟草稿 PCM 时写清口型风险。 |

480p 极速 **不要走二采**（已经在目标分辨率）。768p 极速 **优先直出 4-step**，不要先做 8+8。

### 3.4 VDN hybrid — 极速不做

两条刀都对不上：hybrid 不减步、要 ~65GB；turbo 故意停在 **8-NFE**。5090 32GB 装不下。可抄的只有 Ulysses 切 packed。不要把 11.23s（8×B200、仅 denoise）写进来。

### 3.5 Sage3 — 极速必开（已测、工程量为 S）

已在 5090 落地：`--sdpa-backend sage3`，hits=400/400。金线因 MAE FAIL 关着。极速档 **默认打开**（preset 内，不是全局默认）。与 4-step 正交：少步之后每步仍有 SDPA，−17% 还在。不要和 sol_cute 同时开。缺插件硬失败，不要 silent fallback 成「假 sage」。

### 3.6 Tea / Mag — 极速基本不靠

8-step 蒸馏把 cache 的「无聊中段」榨干。Tea/Mag 各 skip 1，DiT 只 −12%。Mag 质量过脏。4-step 学生轨迹上 Tea 几乎不跳。**极速主路径关 cache。** 只有「做了 8-step 中档、还不想换 LoRA」才允许 Tea 0.04 当安慰剂。

### 3.7 Ulysses — 金线与极速都要，但角色不同

- **金线：** 唯一同轨迹刀。默认 U=1。过 MAE 才留。
- **极速：** 4-step 之后 DiT 仍可能是 13–16s（480p）或 50–70s（768p 单卡，**推断**）。8 卡切这一截值得。TE/VAE **不随 U 变便宜**。无 NVLink：**TP=1，U∈{2,4,8}**；不要从 TP2 起步；U=7 非法。
- 本仓 **尚未实现**。实现合同见 [next-opt-plan P1](./2026-09-11-h3c-next-opt-plan.md)，**默认仍不得改**。

### 3.8 TAE 解码 — 极速 P1，金线永关

4-step 之后，单卡 480p 的 VAE ~8s 会占 e2e 20%+。TAEH3 是 Sol 草稿成片用的同一类刀。本仓金线合同是 fp16 tile+deblock；极速允许换轻量解码。音频仍走官方 audio VAE（「有声可用」），**不要**对 PCM 做 TinyVAE。768p 上官方 VAE 20–35s（**推断**）更值得换 TAE。

| 金线 8-step + Ulysses（不接 4-step） | **65–125s**（最可能 **70–110**） | **推断**（估时文场景 A） |
| **极速：4-step + Sage3 + Ulysses + 官方 VAE** | **40–70s**（最可能 **45–60**） | **推断**（DiT 减半再切卡；VAE 20–35 仍重） |
| **极速 + TAE** | **28–48s** | **推断** |
| 对齐 RH 整栈 BF16 常驻 | **45–90s 或显存失败** | 32GB 装不下 60–66 GiB；offload 不会线性降到 28.7 |
| RH 28.7s / Super Accel 6.85s | **禁止写** | 6000D 8 卡 / 2×GB200 |

8 卡故事比单卡残酷：4-step 把 DiT 砍半之后，**TE+VAE 立刻成为主项**。没有 TAE 和 TE 刀，8 卡极速 480p 很难稳定低于 ~22s，768p 很难稳定低于 ~40s。
