# VDN / 线性注意力机理级研究（只读）

> 来源：子代理 `e4780569-8a58-4b12-a3c8-9367f614c278` 交付（只读）。基于 arXiv:2609.20744（VDN 论文全文）、openvdn.github.io、Gated DeltaNet (2412.06464)、SLA (2509.24006) 第一手材料。用户指出 VDN 的核心是「线性」，此前被一句「换权+换合同+硬件外」打发是机理盲。

## 一、VDN 是什么 —— 纠正误读

**VDN 不是纯线性注意力，是「按时间角色分工」的混合架构（hybrid）。** 论文§2 把 video-video 注意力按时间距离切两条互补分支：

| 分支 | 管什么 | 形式 | 为什么 |
|---|---|---|---|
| **局部 Softmax** | 邻近帧（滑窗=15 latent 帧=3 VAE chunk）+ 首尾帧边界锚点 | 精确逐 token softmax O(N·w) | 高频纹理/物体边界/短程运动靠**精确**逐 token 匹配 |
| **线性记忆（双向）** | 远处帧上下文 | O(N) 递归状态压缩 | 远距离只需主题身份/场景布局/长程运动等**全局低频** |

**这个分工本身就是答案**：VDN 自己承认线性注意力会丢视频需要的高频细节——所以高频留给精确 softmax 窗口，线性分支只背「全局一致性」。text/audio 交互全保留精确 softmax，只有 video-video 远距离走线性。

**实测**：8×B200 上 14.3s/768p DiT 去噪 6.70s，对 50-step dense H3 基线 14.5×。但 14.5× 是三因子叠乘：混合注意力单卡 B200 **仅 2.6×**（799.6→307.9s）×8-step 蒸馏 6.25× ×8卡分布式 7.36×。**线性分支本身贡献就是那 2.6×，不是 14.5×。**

### VDA（Video Delta Attention）精确机制

标准 delta 规则逐 token 更新：`S̄_t = S_{t-1}·Diag(α_t)`（衰减门），`S_t = S̄_t + β_t(v_t − S̄_t·k_t)k_tᵀ`（纠错式写入）。关键在 `(v_t − S̄_t·k_t)`：状态先用当前 key 预测值 `S̄k_t`，再写**预测残差**——联想记忆的「先读后改」，定点覆盖某个 key 的旧值而不污染其它方向。

**VDA 创新 = 逐 token 规则改逐帧规则**。视频一帧 U 个空间 token 同时出现，强加 patch 顺序不自然且相关写入互相干扰。VDA 把整帧当联合最小二乘（式4）：`S_t = argmin ½‖S−S̄_t‖²_F + ½Σβ‖S·k−v‖²`，闭式解 `S_t = (S̄_t + B_t)(I + A_t)⁻¹`。**`(I+A_t)⁻¹` 这个逆**把重叠 key 方向耦合一起解，避免相似 patch 各写各的互相打架；且继承状态转移谱范数≤1（非扩张），稳定性白拿。

## 二、线性注意力第一性原理

**结合律技巧**：softmax O(N²) 因每 query 与全 key 算 `softmax(QKᵀ)V`。线性注意力换 `φ(Q)(φ(K)ᵀV)`，结合律先算 `φ(K)ᵀV` = **d×d 状态矩阵**，扫一遍建一次（O(N·d²)），所有 query 复用 → 对 N 是 **O(N)**。数学上=线性 RNN/fast-weight 状态/SSM：整个 KV 历史压进固定 d×d 矩阵。

**核心权衡（用户强调的「线性」本质代价）**：

| | 精确 softmax | 线性/delta |
|---|---|---|
| KV 历史 | 逐 token 精确亲和力 | 压进固定 d×d，容量不随 N 涨 |
| 复杂度 | O(N²) | O(N)，decode 恒定内存 |
| 丢失 | — | 精确长程 pairwise、尖锐检索（state 装不下细节） |
| 得到 | — | 线性复杂度+恒定内存 |

**丢失的正是稀疏检索/高频细节**：N 涨而状态仍 d×d，更多信息被迫共享固定容量——subject identity/scene layout 这种弥散全局低频能活，「远处像素精确纹理/运动边缘」这种稀疏高频尖锐检索被压掉。

## 三、为什么线性对视频「又长又痛」

视频 DiT 序列极长（480P≈16k，768P≥64k），O(N²) 在长 N 主导（VDN 实测 dense H3 softmax 占去噪 runtime >85%）。线性 O(N) 渐近占优。**但**视频要的恰是高频时空细节，而固定状态压缩丢的就是这个——所以纯线性直接用在视频上掉质量，VDN 必须用混合救。**实测**（VDN Fig 5/8/9，768p/14.3s）：8-step VDN-H3 五指标追平甚至略超 50-step Dense H3，RAFT 运动量 11.71 vs 11.55 基本保住（4-step FastH3 塌到 9.19）。**限定**：这是混合+三阶段对齐+LoRA+8步蒸馏全套训练后的结果，非免训练即插即用。

## 四、线性 vs 稀疏 —— 16k/64k 诚实对比

| 维度 | 稀疏（sol/SVG/LoSA） | 线性（DeltaNet/VDN） |
|---|---|---|
| 注意力形式 | 保留精确 softmax，只算高质量块 | 改变形式为递归状态更新 |
| 渐近 | O(N·k) | **O(N)** |
| 内存 | 仍 O(N·k)，KV 全留 | **恒定** d×d |
| 近似性质 | 有界（保留块上精确） | 有损压缩（整个 map 被压） |
| 训练 | 可免训练 | 通常必须训练/微调 |
| 质量 | 保留块上逐 token 精确 | 全局可、尖锐检索弱 |

**能否结合？——能，且是最前沿两个做法**：①VDN 式（时间分：近窗 softmax+远线性状态）；②**SLA 式（2509.24006，更贴我们 sol）**：按注意力权重分——critical 块走精确 FlashAttention、marginal 块走线性（成本<0.5%）、negligible 跳过，稀疏度从 70%→95% 不掉质量，线性分支当「可学习补偿项」。**这条对我们 sol 栈直接可借鉴。**

## 五、框架误分类确认

`acceleration-mechanisms.md` 把「注意力加速」压进族2（稀疏）。**线性注意力不属于族2**：
- **族2（稀疏）消「注意力连接数」**——保留 softmax 形式，只少算块，损失=丢弃的注意力质量。
- **线性注意力消「softmax 二次形式本身」**——逐对亲和力换固定状态递归，损失=整个 map 有损压缩。

判据（用框架自己检查单第1条「消什么」）：稀疏消「算哪些块」，线性消「softmax 形式」。**不同族。** 建议：线性/混合注意力升为族2 并列新族（族2b 或独立成族），标注损失谱（有界近似 vs 有损压缩）、训练依赖（可免训练 vs 通常需训练）、渐近（O(Nk) vs O(N)）不同。SLA 和 VDN 是「稀疏×线性」混合两实例，证明两族可组合非互斥。

## 六、诚实裁决 —— 模型否决，机制重开

**承认**：之前一句「换权+换合同+硬件外」是**机理盲**——把 VDN 的「产品形态」（训练好的 H3 权重+B200 kernel）和「机理贡献」（线性/混合注意力治长视频）混为一谈，用否决前者错杀后者。

**分两层**：

**(1) VDN-the-model：维持否决，但理由现在是对的。** 要训练（三阶段对齐+LoRA+蒸馏）、换学生权、配套 sm_100/B200 kernel、加速叙事不含 VAE——对本仓保质量加速现有 pipeline 确实合同外+硬件外。

**(2) 线性/混合注意力机制：合法且被低估，对 768P 内存墙尤其，应重开。** 
- **768P 的墙是 O(N²) 注意力矩阵无处安放**（≥64k，全 sol 在 32GB OOM）。稀疏 softmax 把计算降到 O(N·k) 但**仍要物化 KV、仍算保留块**——没消除内存里的二次结构，只是打折。**线性注意力恒定 d×d 状态根本没有那个 O(N²)/O(Nk) 矩阵要物化**——这是稀疏在原理上给不出的东西，恰命中我们被内存墙卡死的场景。
- 但纯线性丢视频高频（VDN 自认），可操作形态是**混合**。

**两条可借鉴、不违合同的路径**（按契合度排序）：
1. **SLA 式「稀疏+线性补偿」叠加在 sol 上（最优先）**：marginal 块用线性近似成本<0.5%、稀疏度 70%→95% 不掉质量。已有 sol 稀疏（480p 400/400）。给 sol marginal 块加线性分支，是现有稀疏栈上的**增量**，推高稀疏度且线性恒定状态正好缓解 768P 内存。需少量微调（SLA 是 fine-tunable），远轻于 VDN 换底座。
2. **VDN 式「窗口 softmax+线性全局」仅用于 768P 远距离帧**：480P(16k) 已被 sol 解（400/400）不动；768P(64k+) 远距离帧上下文用双向线性状态背、近处保留窗口精确 softmax——直接移植 VDN 架构决策治 768P 内存墙。

**一句话**：线性注意力不是族2 变体，是改了注意力数学形式的另一族，其 O(N)+恒定内存恰好命中 768P 被 O(N²) 内存卡死的墙，而稀疏 softmax 给不出这个性质。**VDN-模型否决不变，但线性/混合注意力机制应从「拒绝」改为「重开调研」，优先落点=SLA 式稀疏+线性混合叠加在现有 sol 栈上**——而非把 VDN 整模型搬进来。
