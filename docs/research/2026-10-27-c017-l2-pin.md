# C017 L2 AccessPolicyWindow pin (2026-10-27)

## What
Opt-in `H3_CUDA_L2_PIN=1` pins the device ConvRot Hadamard table (`d_hadamard`, gs²×f32) into the stream **persisting** L2 window via `cudaStreamSetAttribute(...AccessPolicyWindow)`.

## Why
sm120 frontier M3: small hot tables re-read every layer; weights themselves exceed 96MB L2. Bit-identical (attribute only). Est. −0.05–0.15s/clip — not a KPI headline.

## Behavior
- Default **off**.
- Sets `cudaLimitPersistingL2CacheSize` once (~¼ L2, clamped).
- Pins on `ensure_hadamard` / `set_op_stream` rebind.
- One window per stream → prefer f32 H over f16.
- Logs `l2_pin: persisting_l2_limit=…` and `l2_pin: OK tag=hadamard_f32 bytes=…`.

## Non-goals
- Does not re-enable EPI_FUSE.
- Does not pin per-layer `s_channel` / RoPE device buffers yet (follow-up).
