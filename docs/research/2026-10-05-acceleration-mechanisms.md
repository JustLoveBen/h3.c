# 视频扩散加速的机理级分析：速度到底从哪来

> 来源：子代理 `423bdea1-d9a0-43a9-84af-146b8ef744e2` 交付（只读）。本文以「底层被利用的冗余/结构」为组织轴（而非产品名），是评判任何新加速方法的**机理标尺**。每族给出：第一性原理（速度从哪来）、代价杠杆（付什么）、优缺点、可组合性、代表方法及其实测数字与语境。

---

## 机理族 1：减少函数评估次数（NFE/step reduction）

**(a) 第一性原理**：扩散生成 = 数值积分一条 ODE/SDE 轨迹。总耗时 ≈ `NFE × 单次前向耗时`，且 NFE 严格串行。减 NFE 是唯一同时作用于「计算量」和「串行链长度」的杠杆。两子路线：
- **更好的求解器（training-free）**：扩散 ODE 半线性。DPM-Solver 用常数变易法把线性项**解析解出**（零离散误差），剩余用指数积分器高阶近似。UniPC 统一预测-校正任意阶。
- **蒸馏（training）**：训练学生直接逼近多步积分净效果。Consistency 学点到终点映射；DMD/DMD2 让学生输出分布匹配教师分布。2026 Decoupled DMD：真正驱动少步质量的是被忽视的 CFG-Augmentation 项（引擎），分布匹配项是稳定器（盾牌）。

**(b) 代价杠杆**：求解器=离散误差随步长幂次增长（平滑可预测）；蒸馏=蒸馏差距+容量天花板，失去 CFG/步数自由度，视频上运动塌缩（SGTS 退化成学一步生成器）。

**(c) 优点**：加速比最大（求解器 2.5× 免费；蒸馏 10×+）；求解器零训练；蒸馏后与「降单次前向成本」各族完全正交（步数 × 每步成本独立因子）。

**(d) 缺点**：求解器极低步数（<8）失效；蒸馏需训练算力、质量天花板被教师锁定、运动塌缩/细节糊、劣化难诊断。

**(e) 可组合性**：与族 2/3/5/6 完全正交乘性。与族 4 缓存**部分重叠**（都吃相邻步冗余；蒸馏后缓存空间塌缩）。与族 8 互斥。

**(f) 代表**：DPM-Solver（NeurIPS'22，10–20 NFE 达原 50–100 NFE）；UniPC（5–10 NFE 更优）；DMD2（一步 FID 8.35 超教师，但靠 GAN loss 真实数据）；Phased DMD（指出视频蒸馏坑在中间步无监督）；VORTA 报 PCD 蒸馏单用 8.29×（6 步）。

## 机理族 2：注意力稀疏化

**(a) 第一性原理**：全注意力 O(N²d)，但 softmax 后质量高度集中——视频 DiT 三种结构：①空间/时间能量指数衰减（Radial）；②头部分工（SVG：空间头/时间头）；③语义聚类（SVG2/NSA/MoBA）。只算高质量 QK 块。NSA 核心论点=**算术强度平衡**：块粒度须让 tensor core 吃饱。

**(b) 代价杠杆**：近似误差 ∝ 丢弃的注意力质量。静态（Radial）取决于假设是否成立；动态（SVG 1% profiling）误差小但有 ~3% 开销；可训练（NSA/MoBA）保真最高但要改训练。

**(c) 优点**：作用单前向内部，与 NFE 缩减乘性（VORTA 1.76×，叠 PCD 到 14.41×）；视频越长收益越大；免训练版即插即用。

**(d) 缺点**：**理论稀疏≠实际加速**（散乱内存访问致 tensor core 利用率崩塌）；注意力仅占 DiT ~75%（Amdahl）；静态对快速大运动失效。

**(e) 可组合性**：与族 1/4/5/6 正交。与族 3 token 缩减**强重叠**（都减注意力有效 N）。与族 5 sage 直接相乘（稀疏定算哪些块、量化定每块多快）。

**(f) 代表**：SVG（ICML'25，CogVideoX 2.28×/Hunyuan 2.33×，PSNR~29，H100）；SVG2（NeurIPS'25，2.30×，PSNR 30）；VORTA（1.76× VBench 无损，叠 PCD 14.41×）；Radial（NeurIPS'25，默认 1.9×，4× 长视频 3.7×）；NSA（DeepSeek，64k 前向 9×）/MoBA（Moonshot）。sol/LoSA 属同族工程变体。

## 机理族 2b：线性/混合注意力（2026-10-05 补，源自 VDN 深拆 e4780569）

> 此前本框架把「注意力加速」压进族2（稀疏），VDN 深拆确认这是**误分类**——线性注意力改了注意力的数学**形式**，而非「算哪些块」，应独立成族。

**(a) 第一性原理**：softmax O(N²) 因 `softmax(QKᵀ)V` 逐对算。线性注意力换核特征映射 `φ(Q)(φ(K)ᵀV)`，结合律先算 `φ(K)ᵀV` = **固定 d×d 状态矩阵**（扫一遍建一次），所有 query 复用 → **O(N)**。数学上=线性 RNN/fast-weight 状态/SSM：整个 KV 历史压进固定容量状态。**delta 规则**（VDN/DeltaNet）在此基础上加「先读后改」纠错写入（`(v−Sk)kᵀ`）+ 衰减门，定点覆盖旧关联不污染其它方向，检索力远强于朴素累加版。

**(b) 代价杠杆**：固定 d×d 状态是对整个注意力 map 的**有损压缩**——容量不随 N 涨，N 越大越多信息被迫共享。丢失的恰是**稀疏高频尖锐检索**（远处像素精确纹理/运动边缘），弥散全局低频（主题身份/场景布局）能活。**这是与稀疏（有界近似、保留块上逐 token 精确）本质不同的损失谱。**

**(c) 优点**：**O(N)+恒定内存**——稀疏 softmax 仍要物化 O(N·k) KV，线性**根本没有二次/线性注意力矩阵要物化**。这命中长视频/768P 的 **O(N²) 内存墙**，是稀疏在原理上给不出的性质。decode 恒定内存。

**(d) 缺点**：纯线性直接用在视频上掉质量（丢高频）；通常**必须训练/微调**找回质量（vs 稀疏可免训练）。VDN 论文自认直接全替换为线性「meaningfully degrades generation quality」。

**(e) 可组合性**：与族2 稀疏**可组合非互斥**——前沿两个混合范式：①VDN 式（时间分：近窗精确 softmax 背高频 + 远线性状态背全局）；②SLA 式（按注意力权重分：critical 块精确 + marginal 块线性<0.5% 成本 + negligible 跳过，稀疏度 70%→95% 不掉质量）。与族 1/4/5/6 正交。

**(f) 代表**：VDN（arXiv:2609.20744，混合架构，单卡 B200 混合注意力仅 2.6×，14.5× 是叠 8-step 蒸馏 6.25× × 8卡 7.36×）；Gated DeltaNet（2412.06464，delta 规则机制）；SLA（2509.24006，稀疏+线性补偿混合）。**对本仓**：VDN-模型合同外（训练+换权重+B200 核），但「线性/混合注意力机制」对 768P 内存墙是合法被低估方向——优先落点 **SLA 式稀疏+线性混合叠加在现有 sol 栈上**（marginal 块加线性分支，恒定状态缓解 768P 内存，需少量微调）。详见 `2026-10-05-vdn-linear-attention.md`。

## 机理族 3：token 级缩减

**(a) 第一性原理**：非所有 token 携独立信息（相似 patch/静态背景/跨帧重复）。合并/剪枝后进昂贵层再恢复。**与族 2 本质区别**：族 2 保留所有 token 只少算连接；族 3 让 token 真变少——**每一层都变便宜**（注意力 O(N²)、FFN O(Nd²) 全减）。AsymRnR 非对称设计基于：冗余度在不同 block/step/特征类型间差异巨大。

**(b) 代价杠杆**：信息不可逆损失（合并 token 若实有差异——高频纹理/运动边缘/小物体——无法恢复）；3D-RoPE 兼容性。

**(c) 优点**：同时作用注意力和 FFN（族 2 只碰注意力）→ 对 FFN 占比高模型更有效；免训练架构无关；附带显存收益。

**(d) 缺点**：**GPU 效率陷阱**（ToMA 批评：ToMeSD 的匹配/排序/散写在配 FlashAttention 时吃掉理论收益——FLOPs 省 wall-clock 不省）；高动态/高纹理损失明显；工程侵入性高于注意力稀疏。

**(e) 可组合性**：与族 2 强重叠；与族 1/4/5 正交；与族 4 有协同（matching cache 跨步复用相似度）。

**(f) 代表**：ToMeSD（2023，SD1.5 60% 合并→2.03×/5.68× 显存，FID 几乎不掉——图像+旧架构）；AsymRnR（ICML'25，Q/KV 非对称+matching cache，CogVideoX VBench 无损）；ToMA（ICML'25，重写 GPU 友好后 SDXL/Flux 仅 24%/23%——是评估本族真实天花板参照）。

## 机理族 4：跨步/跨层冗余利用 —— 缓存

**(a) 第一性原理**：相邻步输入高度相关 → 中间特征/层输出/残差也相关。两本质不同子类：
- **精确不变量缓存（bit-identical）**：文本 embedding、RoPE 表、AdaLN conditioning 全程真常量——缓存是删重复计算，零误差，白捡。
- **近似特征缓存（bounded error）**：TeaCache 用 embedding 差异预测输出差异；MagCache 发现相邻残差**幅度比稳定衰减、方向几乎不变**（前 80% 步余弦距离≈0）；EasyCache 用变换向量一阶稳定性+累计误差阈值。三者同源：找便宜代理量预测「重算值不值」。

**(b) 代价杠杆**：陈旧误差沿轨迹**累积**（非独立相加，被后续网络放大/吸收）。阈值=速度/质量旋钮。失效：阈值过松→运动发粘/细节糊/漂移。

**(c) 优点**：免训练、实现简单、数字可观（TeaCache 1.5–2×/MagCache 2.1–2.8×/EasyCache 2.1–3.3×）。

**(d) 缺点**：TeaCache 需离线拟合+prompt 校准（过拟合风险）；PAB 类静态广播要 1.7× 显存；**低步数/蒸馏模型上空间塌缩**（4–8 步每步变化大，相邻步相似前提不成立——与族 1 根本张力）。

**(e) 可组合性**：与族 2/3/5/6 正交（VORTA+PAB 实测 2.35×）；与族 1 部分互斥。精确不变量缓存与一切正交且永远该做。

**(f) 代表**：TeaCache（CVPR'25，1.5–2× 需校准）；MagCache（NeurIPS'25，2.1–2.8× 单样本校准，幅度比衰减律跨 prompt 稳定）；EasyCache（2025.07，2.1–3.3× 零 profiling，Wan2.1 比 TeaCache PSNR 高 11.8%）。

## 机理族 5：量化/低精度

**(a) 第一性原理**：①tensor core 吞吐随位宽下降倍增（4090 INT8=FP16 4×；Blackwell 原生 FP4 MMA）；②内存 bound 算子速度 ∝ 数据体积。**关键区分——「原生低精度 GEMM」vs「反量化后计算」是两个宇宙**：原生才拿倍数；dequantize-then-FP16 只省权重加载带宽，对计算 bound 大 GEMM 几乎零收益。SageAttention 为何成：K 矩阵通道 outlier 结构=共享大 bias+小信号，减 mean(K) 移除 bias 而 softmax 对行减常数**数学精确等价**→中心化后动态范围骤减，INT8 够用，开销<0.2%。

**(b) 代价杠杆**：量化误差，由权重vs激活（激活有动态 outlier 更难）、粒度（per-tensor<per-channel<per-block）、硬件是否有原生 MMA 决定。纹理/暗部/文字最敏感。

**(c) 优点**：与所有算法族正交乘性；PTQ 免训练；显存/带宽双收益，对消费级卡甜点尤其大。

**(d) 缺点**：激活量化是硬骨头（无脑 INT8 激活直接糊图）；硬件依赖极强（Hopper FP8/Ada INT8/Blackwell FP4 甜点不同）；累加器精度隐形坑；反量化开销可吃收益。

**(e) 可组合性**：与族 1/2/3/4 全正交乘性（SOL 引擎核心叠法）。与族 6 深度纠缠（量化收益靠融合 kernel 兑现）。

**(f) 代表**：SageAttention（ICLR'25，~2.1× vs FA2，RTX4090 INT8 甜点）；SageAttention2（ICML'25，QK INT4+PV FP8，~3× FA2）；NVFP4（Blackwell 原生，per-block micro-scaling，~2× FP8——本仓 h3_dit_nvfp4 探索此线）。**反例**：纯 W4A16 反量化在计算 bound DiT 大 GEMM 上端到端收益常<10%（数字多来自 LLM decode 带宽 bound 语境）。

## 机理族 6：消除工程浪费 —— kernel 融合/内存工程/调度

**(a) 第一性原理**：wall-clock ≠ FLOPs/峰值。大量时间在 launch 开销、内存往返（kernel A 写 HBM→B 读回，中间结果本可留 register/SMEM）、串行气泡、冗余初始化/重载。融合（QKV-merge/QKNorm+RoPE/RMS+AdaLN/GEMM+epilogue）让中间结果不出 SMEM；CUDA Graph 整段 launch 录制一次提交；stream overlap 让独立工作并行；pinned+异步 D2H 消同步等待。

**(b) 代价杠杆**：**没有质量杠杆**。八大族中唯一可 bit-identical（或仅浮点结合序差异）。代价是纯工程：kernel 开发/调优人力、shape 特化、可维护性下降。

**(c) 优点**：免费的速度、质量零风险、永远该先做；与所有族正交，且是其他族的**兑现前提**（稀疏/量化/token 缩减的理论收益都要靠融合 kernel 变 wall-clock）。

**(d) 缺点**：收益天花板受浪费占比限制；CUDA Graph 要求 shape 静态；人力密集、硬件特定。

**(e) 可组合性**：与一切正交且为**乘性基底**——把其他族理论加速比兑现为实测的汇率。正确顺序：先 profile 定位浪费→本族收割免费部分→再上带质量杠杆的族。

**(f) 代表**：FlashAttention 本身即本族丰碑（不改数学靠 tiling 2–4×）；fused epilogue/QKV 融合 10–30%；CUDA Graph 固定 shape 小 batch 1.2–1.5×。本仓 QKV-merge/fused epilogue/VAE prewarm/resident 权重均属此族——是「地基」非「选项」。

## 机理族 7：并行化/系统级

**(a) 第一性原理**：单卡装不下/算不完→切到多设备/时间轴。不减计算，**摊还计算与容纳工作集**。Ulysses 序列并行通信量随 GPU 数下降但对拓扑极敏感（CoCoDiff 实测 all-to-all 占推理 64%→96%）；Ring/USP 可重叠通信；PipeFusion 通信最低；CPU offload 买「装得下」付 PCIe 延迟=**能力杠杆非速度杠杆**；continuous batching 只多请求有意义。

**(b) 代价杠杆**：通信开销 vs 并行收益，存在最优点。

**(c) 优点**：唯一能「装下本来装不下的模型/分辨率」的族（能力维度）；与所有算法族正交。

**(d) 缺点**：对单 GPU 延迟场景完全不适用；通信主导时加卡变慢；工程复杂度高。

**(e) 可组合性**：与族 1–6 全正交（不同轴）。

**(f) 代表**：xDiT/USP（Ulysses 3 节点 ~½ 单节点）；CoCoDiff（2026，并行化瓶颈=通信实测主导）；PipeFusion。**单卡结论**：本族对本仓单 5090 目标主要价值是**负面知识**——避免把多卡论文数字误当单卡可达。

## 机理族 8：换模型/换轨迹（改合同）

**(a) 第一性原理**：前七族加速同一问题；本族**改问题本身**。LTX-Video：patchify 挪到 VAE 输入，32×32×8 时空压缩（1:192，pixel-to-token 1:8192，典型值 4×）→ 序列骤降 → H100 上 5s 视频 2 秒生成；VAE decoder 兼末步去噪补细节。自回归视频（CausVid）换轨迹范式。

**(b) 代价杠杆**：不再是原模型——质量合同/能力边界/生态全重置。高压缩 VAE 代价=高频细节上限。

**(c) 优点**：加速比可数量级；常同时降显存门槛。

**(d) 缺点**：对「优化现有 pipeline」**N/A 而非「被否决」**——不是候选优化手段，是候选替代产品。放进优化对比表是范畴错误，放进「要不要换底座」战略表才正确。迁移成本：权重/LoRA 生态/评测基线全换。

**(e) 可组合性**：作为新底座后族 1–6 仍可叠加。与「优化原模型」互斥（二选一投资决策）。

**(f) 代表**：LTX-Video（2025.01，1:192 VAE，H100 5s@768×512 用 2 秒；0.9.7 蒸馏版 4–10 步）；少通道/高压缩潜空间同此理。

# 合成：机理地图

## 速度来源统一视图

| 族 | 利用的冗余/结构 | 作用的量 | 损失谱 | 典型幅度 |
|---|---|---|---|---|
| 1 求解器 | ODE 半线性结构 | NFE | 无损→微损 | 2–3× |
| 1 蒸馏 | 多步积分可压缩性 | NFE | 有损 | 5–10×+ |
| 2 注意力稀疏 | 注意力质量集中 | 每步注意力 FLOPs | 近似误差 | 1.7–2.3× |
| 3 token 缩减 | token 间信息冗余 | 每步所有层 FLOPs | 信息不可逆损失 | 1.2–2× |
| 4 特征缓存 | 跨步特征相关性 | 有效 NFE | 陈旧误差累积 | 1.5–3.3× |
| 4 不变量缓存 | 真正的常量 | 冗余计算 | **bit-identical** | 视占比 |
| 5 量化 | 数值精度冗余+硬件甜点 | 单算子成本 | 量化误差 | 1.5–3×（算子级） |
| 6 工程消除浪费 | launch/内存往返/气泡 | wall-clock 非数学部分 | **bit-identical** | 1.1–1.5× 且是兑现前提 |
| 7 并行化 | 设备间算力聚合 | 资源/能力 | 无损（通信换） | 能力>速度 |
| 8 换合同 | 问题重定义 | 一切 | 合同变更 | 数量级 |

## 正交 vs 重叠（叠乘规则）

- **乘性正交组**：{1} × {2 或 3 取一} × {5} × {6}——分别作用「算几次 × 每次算多少 × 每算子多快 × 浪费多少」四独立因子。VORTA 1.76×（族2）×8.29×（族1）≈14.41× 实测即此乘性证据。
- **重叠递减对**：1↔4（都吃相邻步冗余）；2↔3（都砍注意力有效规模，可部分解耦：3 管 FFN、2 管注意力连接）；5↔6（不重叠但强耦合）。
- **永远先做零风险**：族 6 + 精确不变量缓存。
- **轴外**：族 7（几个卡）与族 8（哪个模型）是决策轴，不是优化手段。

## 无损 ↔ 有损谱

```

(族6)    (族4-精确)  (族1-solver) (族5,经平滑) token缩减   (族1)   (族8)

```

## 用机理评判任何新方法的检查单

1. **它消的是什么？**（NFE/token/注意力连接/位宽/launch/串行/问题规模）→ 定位到族，立刻知道理论上限与 Amdahl 边界。
2. **代价杠杆是什么？** 无质量杠杆（族 6/精确缓存）→ 无脑做；有质量杠杆 → 问误差在谱上哪、如何随旋钮缩放。
3. **数字的语境是什么？** 端到端还是算子级？什么卡（INT8 甜点 vs FP8 甜点）？多少步基线（缓存/稀疏在高步数基线虚高，叠蒸馏缩水）？多长序列（稀疏随 N 涨）？
4. **与已有栈共享哪块冗余？** 同族或共享冗余 → 预期叠加 ≤ 独立数字之积，按重叠折扣估。
5. **理论 FLOPs 收益有没有配套 kernel？** 没有融合 kernel 的稀疏/合并/量化，按「FLOPs 收益 × 0.3–0.6」折算 wall-clock（ToMA/ToMe、SVG2/前代稀疏教训）。

**这套机理框架的意义**：此后任何新方法出现，不需重新做「是否适用于我们」的裁决——先问它**消什么、付什么、在谱上哪里、和谁重叠**，答案自然浮现。

3. **「稀疏训进权里」上限高于推理期稀疏**：FastH3 的 VSA（训练进权）/ SLA2（可学习路由+QAT，95–97% 稀疏质量不输 full）/ VDN 保运动>FastH3 → 共同指向「推理期稀疏（我们 sol_cute）有上限，稀疏感知微调是演进方向」。

### 一处实质冲突（需主动复核，不可回避）

**Hao AI Lab / FastWan 论点：训练无关稀疏在 <10 步蒸馏下急剧退化。** 这与我们「turbo4(4-step 蒸馏） + sol_cute（推理期训练无关稀疏）」组合直接冲突。现状：480p hits=400/400 说明路由在跑，但**未验证在 4-step 蒸馏轨迹上稀疏是否仍质量无损**（sol 官方甜区是 50-step/768p 长序列）。**行动：复核 sol_cute @ turbo4 的实际稀疏有效性（waffle/人眼对全 dense），若退化则 sol_cute 只能留 8-step 金线档或需 SLA2 式稀疏感知微调。**
